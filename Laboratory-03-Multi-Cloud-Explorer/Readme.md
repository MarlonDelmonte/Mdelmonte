## Activity Overview

This laboratory activity explores three major cloud computing platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

## Cloud Platforms

* Amazon Web Services (AWS)
* Microsoft Azure
* Google Cloud Platform (GCP)

## Linux Investigation

The KillerCoda Linux playground was used to identify the following:

* Operating System
* CPU Information
* Memory
* Disk Space

### Linux Commands Used

```bash
cat /etc/os-release
lscpu
free -h
df -h
```

### Linux Server Migration

If this Linux server were migrated to the cloud, it could be hosted using virtual machine services from all three providers:

| Provider | Service                |
| -------- | ---------------------- |
| AWS      | Amazon EC2             |
| Azure    | Azure Virtual Machines |
| GCP      | Compute Engine         |
