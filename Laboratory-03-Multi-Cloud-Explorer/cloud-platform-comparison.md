## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest ranges of cloud services. It provides services for computing, storage, networking, databases, security, analytics, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the best choice for organizations that already use Microsoft technologies. It works well with products such as Windows Server, Microsoft 365, and Microsoft identity services.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for Artificial Intelligence and Kubernetes. Google Cloud provides AI and machine learning services and Google Kubernetes Engine (GKE).

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides many different cloud services and supports both small and large organizations. It also provides a large global infrastructure and many options for building applications.
