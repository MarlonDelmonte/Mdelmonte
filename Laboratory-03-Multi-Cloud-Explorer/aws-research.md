# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers many cloud services for computing, storage, databases, networking, security, and other business needs.

## Global Infrastructure

AWS has data centers organized into Regions and Availability Zones around the world. Each AWS Region contains multiple Availability Zones that help organizations build highly available applications.

## Cloud Management Console

The AWS Management Console is a web-based interface used to create, configure, monitor, and manage AWS resources.

## Four Core Services

1. **Amazon EC2** – Provides virtual servers for running applications.
2. **Amazon S3** – Provides object storage for files and data.
3. **Amazon VPC** – Provides networking for AWS resources.
4. **AWS IAM** – Controls access to AWS resources.

## Three Advantages

1. AWS provides a wide range of cloud services.
2. AWS has a large global infrastructure.
3. AWS supports scalable and highly available applications.

## Typical Enterprise Use Cases

AWS can be used for websites, mobile applications, data storage, databases, backup systems, enterprise applications, and large-scale online services.
