# Reflection

This activity was my first time using a cloud-based Linux environment and working with GitHub for a Cloud Computing laboratory. At first, I was not familiar with the Linux terminal and its commands, but I slowly learned how to use them.

I learned how to check my username, current directory, hostname, system information, memory, and disk space. I also learned how to create folders and Markdown files using Linux commands.

Another thing I learned was how to create a GitHub repository and organize my laboratory files. I learned that GitHub can be used to keep my activities and projects in one place.

Overall, this activity gave me a basic understanding of Linux, cloud environments, Markdown, and GitHub. I think these skills will be useful in my future Cloud Computing activities.
